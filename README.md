# Игры разума (Python)

## Установка

**Требования:** Python 3.14 или новее, Git, uv и Make.

Выполните команды в терминале:

```bash
git clone https://github.com/askoren1/devops-engineer-from-scratch-project-49.git
cd devops-engineer-from-scratch-project-49
make install
make build
make package-install
```

## Использование

Команды, которые можно вводить в терминале после установки:

| Команда | Что запускает |
|---|---|
| `brain-games` | Приветствие и знакомство с игроком |
| `brain-even` | Проверка на чётность |
| `brain-calc` | Калькулятор |
| `brain-gcd` | Наибольший общий делитель |
| `brain-progression` | Арифметическая прогрессия |
| `brain-prime` | Проверка простого числа |
